Data engineering projects   

A collection of foundational data engineering projects inspired by the Udacity Data Engineering Nanodegree. It covers relational and NoSQL databases, ETL pipelines, workflow orchestration, and deployment of ML applications.

1. Postgres data modelling project
- A data pipeline to download financial stock data, load it into a local PostgreSQL database
- Supports incremental data loading to keep the database up-to-date    

2. MongoDB database project
- A data pipeline to extract data from CSV files and load them into MongoDB collections

3. Airflow full data loading pipeline project
- An extension of the postgres_etl project using Airflow to orchestrate the data pipelines. - Performs full data loading 

4. Deploy mini project with Streamlit and FastAPI  
- An end-to-end ML web application where users can upload input data and receive real-time predictions.
- Streamlit handles the frontend UI, while FastAPI serves as the backend ML inference API.
